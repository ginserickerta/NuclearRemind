```yaml

```

**คำถาม:**
> เวชศาสตร์นิวเคลียร์จัดการเซลล์เนื้อร้ายเป็น 2 ขั้นตอน ข้อใดถูก?

| | ตัวเลือก |
|---|---|
| A | PET/SPECT ยิงรังสีทำลายเนื้อร้ายทันทีตั้งแต่ตอนสแกน |

