# ภาค 5 — Bark Pool

**สำหรับ:** `BarkSO` assets · Sprint 4
**หลักการ:** ผูกกับ **state** ไม่ใช่ **day** — ตัวเลขขยับ บทไม่ต้องแก้

---

### กฎเขียนบท (ห้ามละเมิด)

1. **ห้ามให้เครื่องจักรมีเจตนา** — เตาไม่เกลียด ไม่ทรยศ ไม่ฝัน
2. **ห้ามอุปมา** — "กำแพงกั้น" "วินัยของทีม" ตัดหมด
3. **NPC ห้ามสรุปบทเรียน** — ให้ผู้เล่นสรุปเอง
4. **1 บรรทัด = 1 ข้อมูล** — เห็นอะไร / ต้องทำอะไร
5. **ตัวเลขดีกว่าคำคุณศัพท์** — "เก้าสิบแล้ว" > "ร้อนมาก"
6. **ไม่บรรยายท่าทาง** — v8 เขียนกฎนี้เองแต่ละเมิดเอง

### กติกาเทคนิค

```
• สูงสุด 2 bark/วัน (ห้ามเกิน — ไม่งั้นรก)
• conditions AND กันหมด
• priority สูงกว่าชนะ · เท่ากัน = random แต่จำ index กัน repeat
• cooldown นับเป็นวัน
• onceOnly = พูดครั้งเดียวตลอดเกม
```
