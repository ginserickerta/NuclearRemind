# TOKAMAK / COILS — แผนงานค้าง (ยังไม่ทำ · 2026-07-22)

> สถานะ: **ค้างไว้ — เจ้าของจะกลับมาทำเอง** · สรุปการตัดสินใจ + สิ่งที่ต้องทำ เก็บไว้กันลืม

## แนวคิดหลัก (เคาะแล้ว)

**โทคาแม็ค = CORE TOWER** — ไม่ทำเป็นอาคาร "โทคาแม็ค" แยกหลัง (จะกลายเป็นมีเตา 2 ตัวซ้อน สับสน)
หอ CORE TOWER = ห้องพลาสมาตรงกลาง · **คอยล์ที่วิจัย = ขดลวดแม่เหล็กที่ล้อมรอบเตา**

**การวางที่เคาะ: คอยล์เป็น "อาคาร" ที่วางล้อมรอบ CORE TOWER (วงล้อมเตา)**
- ตรงดีไซน์เดิมใน `docs/NOTES.md` → note `confinement` เขียนไว้แล้ว: `unlocksBuildings: [ToroidalCoil, PoloidalCoil]`
- วางบนช่องกริดที่ติดกับ CORE TOWER → พอวางครบ วงแหวนคอยล์ + หอเตากลาง = ประกอบเป็นโทคาแม็คสมบูรณ์ เห็นบนแผนที่จริง
- ใช้ลูปที่เกมมีอยู่แล้ว: วิจัย → ปลดล็อกอาคาร → เอาเหล็กไปวาง (เหมือน DeuteriumExtractor, ZoneB)

## 🔴 บั๊กที่ต้องแก้ (สำคัญ — ตอนนี้เกมเล่นต่อไม่ได้หลังวิจัยคอยล์)

**วิจัย confinement เสร็จแล้ว → ติดคอยล์ไม่ได้ ไม่มีปุ่มให้กด**
- ตรรกะติดคอยล์ทำงานได้: `CoreTowerManager.InstallToroidal()/InstallPoloidal()` (เช็ค note + หักเหล็ก + เพิ่ม level 0-3) ✅
- แต่ปุ่มสั่งเป็น **null**: ในซีน `toroidalButton: {fileID: 0}` / `poloidalButton: {fileID: 0}`
- สาเหตุ: ปุ่มเดิมอยู่บน "แผงเตาล่างจอ" ที่ถูกลบตามคำขอ (คอมเมนต์ `HUDCanvasSetup.cs:214`) แล้วไม่ได้ย้ายไปที่ใหม่
- ตอนนี้ติดคอยล์ได้เฉพาะแผง debug (F-keys) ซึ่งผู้เล่นจริงเข้าไม่ถึง
- ผลของ confinement (หล่อเย็น +9/ระดับ · ลด HEAT −6/ระดับ) เลยถูกตัดขาดจากผู้เล่นทั้งหมด

## สิ่งที่ต้องทำ (ตอนกลับมา)

**ทางเลือก A — เต็มรูปแบบ (ตรงดีไซน์ · งานเยอะ):** คอยล์เป็นอาคารล้อมเตา
1. สร้าง building asset `ToroidalCoil` + `PoloidalCoil` (ใน `Assets/ScriptableObjects/Buildings/`) — ยังไม่มี
2. อาร์ตอาคารคอยล์ (วงแหวน/ขดลวด)
3. กฎวาง: วางได้เฉพาะช่องที่ติดกับ CORE TOWER · ปลดล็อกเมื่อวิจัย confinement เสร็จ
4. ต่อการวางเข้าระบบคอยล์เดิม (`InstallToroidal/Poloidal` → level +1) แทนการใช้ปุ่ม
5. (เสริม) พอวางครบ วงแหวนล้อมหอเตาให้เห็นเป็นโทคาแม็คบนแผนที่

**ทางเลือก B — เร็ว (แก้บั๊กก่อน · 1 ไฟล์):** ปุ่มติดคอยล์ในแผง Core Tower
- เพิ่มโซนคอยล์ใน `CoreTowerPanelUI` — โชว์ระดับ T0-3/P0-3 + ราคาเหล็ก + ปุ่มติดตั้ง (ล็อกจนวิจัย confinement เสร็จ ตามกฎ #6)
- ทำเสร็จไว ใช้ตรรกะที่มีอยู่แล้ว แค่ต่อปุ่ม

**แนะนำ:** ทำ B ก่อนเพื่อปลดบั๊ก (เกมเล่นจบได้) แล้วค่อยยกระดับเป็น A ถ้ามีเวลา/อาร์ต

## ของเสริม (ทำหลังได้ — เพิ่มความเข้าใจฟิสิกส์)

- event `OnCoilsChanged` ยิงอยู่แล้วตอนติดคอยล์ แต่ตอนนี้เข้าแค่ระบบ records — **ไม่มีอะไรเปลี่ยนบนภาพเตา**
- ถ้าติดคอยล์แล้วมีวงแหวนเรืองแสงปรากฏ (Toroidal = วงแนวนอน · Poloidal = วงแนวตั้ง) พันรอบ CORE TOWER → ผู้เล่นเห็นโทคาแม็คก่อตัวจริง สอนฟิสิกส์ได้ทรงพลังกว่าตัวเลข
