# ภาค 4 — Crisis Cards

**สำหรับ:** `CrisisCardSO` assets · Sprint 4
**หลักการ:** ★ **ตัวเลือกที่ดีล็อก 🔒 จนกว่าจะวิจัย** — นี่คือสิ่งที่ทำให้ความรู้มีค่า

---

### โครงการ์ด

```
┌──────────────────────────────────┐
│ ⚠  [หัวข้อ]                      │
│    [บรรยาย 2-3 บรรทัด]           │
│                                  │
│ [NPC line 1 บรรทัด]              │
│                                  │
│ [A] ตัวเลือก                     │
│     ผลในเกม                      │
│ [B] ตัวเลือก                     │
│     ผลในเกม                      │
│ [C] 🔒 ต้องวิจัย [note] ก่อน     │
│                                  │
│ ▸ [Inner Voice]                  │
└──────────────────────────────────┘
```

**กติกา:**
- ตัวเลือกล็อก **แสดงให้เห็น** แต่กดไม่ได้ → ผู้เล่นรู้ว่ามีทางที่ดีกว่า
- **ไม่มีทางเลือกฟรี** — ทุกทางมีราคา
- การ์ดเกิดซ้ำได้ตาม cooldown · Lead ปลดครั้งเดียว
- ★ **การ์ด 4/5/6/7 = ตัวละครชนกัน** — NPC 2 คนเถียงกันในกล่องเดียว ผู้เล่นต้องเลือกข้าง (ดู §ท้ายไฟล์)

### จุดยืนตัวละคร (ใช้เขียนบทชนกัน)

| ตัวละคร | ต้องการ | มองไม่เห็น |
|---|---|---|
| **Kova** | เตาเดิน · CORE ขึ้น | คนที่จ่ายราคาให้เตาเดิน |
| **Mira** | คนไม่ตาย | ว่าถ้าเตาไม่เดิน ทุกคนตายอยู่ดี |
| **Dorn** | ยุ้งไม่ว่าง | อะไรก็ตามที่ไกลกว่าฟาร์ม |

> **Kova ไม่ใช่คนเลว** — เขาถูกเรื่องเตาทุกครั้ง แค่ไม่เห็นคน
> **Mira ไม่ใช่คนดี** — เธอไม่มีทางออกให้ มีแต่ราคาที่ต้องจ่าย

## การ์ด 1 · เตาร้อน
```yaml
cardId:    heat
trigger:   heat > 62
cooldown:  3 วัน
unlockedBy: confinement
```

```
⚠  ความร้อนเกินพิกัด
    HEAT แตะ 62 · หล่อเย็นตามไม่ทัน
    ถ้าถึง 100 เตาหลอมละลาย จบเกม

Kova: "ความร้อนขึ้นเร็วเกินที่หล่อเย็นจะรับไหว"

[A] เร่งไฟเข้าระบบหล่อเย็น
    พลังงาน −250 · คนที่หอควบคุม 3 คนรับรังสี +12
    HEAT −8 เท่านั้น · Hope −4

[B] ลดโหมดเตา รอให้เย็นเอง
    CORE% หยุดขึ้น 2 วัน · HEAT ค่อยๆ ลง

[C] 🔒 ฉีดสารหล่อเย็นฉุกเฉิน
    ต้องวิจัย "ขังพลาสมาด้วยสนามแม่เหล็ก" ก่อน

▸ อีกสิบองศา
```

**เมื่อปลด `confinement` แล้ว:**
```
[C] ✓ ฉีดสารหล่อเย็นฉุกเฉิน
    HEAT −22 ทันที · น้ำ −40
    Kova: "คอยล์รับไหว ฉีดเลย"
```

> **★ การ์ดนี้เล่าเรื่อง 2 จังหวะ**
> ต้นเกม (D5) = ยังไม่วิจัย → มีแต่ทางแย่ · ท้ายเกม (D29 ตอนพายุ) = ปลดแล้ว → มีทางจริง
> **sim: "เล่นดีมาก" เจอแค่ 98% ตอนพายุ · สายอื่น 100% ตั้งแต่ต้นเกม**

    ได้แรงงานคืน · รังสีสะสมเพิ่ม · เสี่ยงตาย

    หยุดงาน · ความล้า +15 · Hope −6
    อาการไม่ดีขึ้นเอง

[C] 🔒 บำบัดด้วยสารเภสัชรังสี
    ต้องวิจัย "รังสีกับร่างกายคน" + สร้าง Med Bay

**เมื่อปลด `nuclear_medicine` + Med Bay:**

**วิธีแก้:** 4 การ์ดที่มีคนสองฝ่ายเสียประโยชน์จริง → ให้เถียงกันในกล่องเดียว

| การ์ด | ชน | Kova ต้องการ | อีกฝ่ายต้องการ |
|---|---|---|---|
| 4 · คนหิว | **Dorn vs Kova** | เหล็กเข้าเหมือง | Dorn: คนกลับฟาร์ม |
| 5 · หมดแรง | **Kova vs Mira** | งานเดินต่อ | Mira: คนได้นอน |
| 6 · Zone B | **Kova vs Mira** | Tritium ไม่หยุด | Mira: ไม่ส่งคนเข้ารังสี |
| 7 · Triage | **Kova vs Mira** | เลือกตามประโยชน์ | Mira: ไม่เลือกใคร |

**กฎการเขียนบทชนกัน:**

1. **แต่ละคนพูดจากปัญหาของตัวเอง** — ไม่ใช่จากธีมของเกม
2. **บรรทัดถัดไปรับของบรรทัดก่อน** — ห้ามพูดสวนทางกันแบบไม่ได้ยินกัน
3. **ไม่มีใครถูกทั้งหมด** — ถ้าผู้เล่นรู้ทันทีว่าควรเลือกข้างไหน = เขียนพลาด
4. **บทปิดไม่ใช่การให้รางวัล** — คนที่ไม่ได้ดั่งใจต้องจำไว้ ไม่ใช่ยอมรับ
5. **เงียบได้** — การ์ด 7 [A] จงใจไม่มีบท: ผู้เล่นทำตาม Kova แล้วไม่มีใครพูดอะไร **เจ็บกว่ามีบท**

**ทำไมไม่ชนทุกการ์ด:**
- การ์ด 1/2/3 = วิกฤตเฉพาะทาง มีคนเดียวที่รู้เรื่อง ยัดคนที่สองเข้าไป = เสียงปลอม
- การ์ด 8 Decree = Mira พูดคนเดียวถูกแล้ว — Kova ไม่มีสิทธิ์เห็นด้วยหรือค้าน มันคือคำสั่งของผู้เล่น

**implement:** บทชนกันคือ field `dialogueLines[]` ใน `CrisisCardSO` (เรียงตามลำดับ ห้ามสลับ)
บทปิด = `CardOption.afterText` ผูกกับตัวเลือกที่กด · ค่าว่าง = เงียบ (ถูกต้อง ไม่ใช่บั๊ก)
