## สิ่งที่แก้ในฉบับ v8 (อ่านก่อนเริ่ม)

1. **ความรู้ต้องมาก่อนควิซ** — เดิมควิซเด้งถามทั้งที่ผู้เล่นยังไม่เคยได้ข้อมูลเรื่องนั้น กลายเป็นเดาสุ่ม ฉบับนี้ทุกควิซมี "จังหวะให้ความรู้" มาก่อนเสมอ ผ่าน 2 ช่องทาง:
   - **Info Card** (ป๊อปอัปข้อมูลสำคัญ) — เด้งตอนทำเควส/ตอนสร้างอาคาร/ตอนวิกฤต ก่อนควิซ
   - **คำบรรยาย / Inner Voice / บท NPC** — เล่าแทรกข้อมูลรองระหว่างเล่น
   → ควิซเปลี่ยนบทบาทเป็นแค่ "คำถามทบทวนสิ่งที่เพิ่งรู้" ไม่ใช่การเดา · ข้อถูกของควิซทุกข้อ ผู้เล่นต้องเคยเห็นคำตอบใน Info Card หรือคำบรรยายก่อนหน้าแล้ว

2. **ตัดบันทึกเสียงแบบเปิดฟังออกทั้งหมด** — เปลี่ยนเป็น "บันทึกข้อความ" ที่ผู้เล่นอ่านเป็นตัวอักษรบนจอ ไม่ใช่เสียงพูด (เนื้อหาปม Elara คงไว้ครบ)

3. **★ เปลี่ยนวิธีส่งบันทึกให้เข้ากับมุมมองเมือง — ไม่ต้อง "เข้าห้อง" คลิกของเล็ก ๆ** — เกม isometric มองทั้งเมืองจากบนลงมา ผู้เล่นไม่ได้เดินเข้าห้อง จึงตัดการคลิกสมุด/จอในอาคารออกทั้งหมด เปลี่ยนเป็นระบบที่เข้ากับ city-view:
   - **★ ระบบ "กู้คืนบันทึก" (Data Recovery)** — บันทึกของ Elara คือข้อมูลเก่าค้างในเครือข่ายของเมือง พอผู้เล่นสร้าง+จัดคนเข้าห้องวิจัย เมืองจะเริ่มกู้คืน/ถอดรหัสข้อมูลทีละส่วนตามหมุดหมาย (สร้างห้องวิจัย → สกัดเชื้อเพลิง → เตาติด → พายุใกล้) เมื่อกู้คืนได้ ระบบเด้งการ์ดบันทึกกลางจอเอง แล้วเก็บเข้า **แผง Records** ข้างจอให้ย้อนอ่านได้ทุกเมื่อ
   - **ป้ายชื่อทีม 6 คน** เปลี่ยนเป็น **อนุสรณ์ (Memorial)** — สิ่งก่อสร้างในฐาน ผู้เล่นคลิกที่ตัวอาคาร (interaction ปกติของ city-view) แล้วเปิดแผงดูรายชื่อ 6 คน

## วิธีเล่าเรื่องในเกมนี้ — 5 ช่องทาง (เด้งบนหน้าจอระหว่างเล่น)

1. **Inner Voice (ความคิดตัวเอก)** — ป๊อปอัปเล็ก ๆ ข้างจอ สั้น 1–2 ประโยค ไม่มีชื่อ เป็นเสียงในใจของ Auren
   > ▸ ความคิด: ไฟไม่พอ... ต้องรีบสร้างเครื่องปั่นไฟ
2. **NPC line** — บทพูดตัวละครอื่น มีชื่อกำกับ สั้น ไม่ยืดเยื้อ
   > Kova: "เตาร้อนขึ้นเรื่อยๆ ทำอะไรสักอย่างสิ"
3. **System log + Event card** — ข้อความระบบ + การ์ดวิกฤต A/B/C (แบบ Frostpunk)
4. **★ Info Card (การ์ดข้อมูล)** — ป๊อปอัปความรู้ที่เด้ง **ก่อน** จังหวะที่จะมีควิซ สั้น กระชับ อ่านจบใน 3–4 บรรทัด แล้วค่อยมีควิซทบทวนตามมา
5. **★ Record Card + แผง Records** — การ์ดบันทึก Elara เด้งกลางจอเองตอนกู้คืนสำเร็จ (ผู้เล่นอ่าน) แล้วเก็บเข้าแผง Records ข้างจอ

### หลักการเขียน (ตามที่กำหนด)
- ไม่บรรยายกิริยาท่าทางตัวละคร — ไม่มี "กำมือแน่น" "มองขอบฟ้า"
- บทพูดน้อยมาก — เน้นที่เควสและการ์ด ไม่ใช่บทละคร
- ภาษากระชับ ห้วน แบบเกมบริหารจริง

### ตัวละคร (NPC)
- **Auren Vasek** — ตัวเอก (Inner Voice) วิศวกรคนสุดท้ายที่รอด
- **Kova** — หัวหน้าช่าง นำวิกฤตเตา/ฟิวชัน สอนระบบพื้นฐาน
- **Mira** — แพทย์/รังสี นำวิกฤตโรค + ประเด็นความปลอดภัยของคน (ALARA)
- **Dorn** — หัวหน้าฟาร์ม/ชาวนา (ปลดช่วงเฟส 3 เกษตร) นำวิกฤตเสบียงเน่า
- **Dr. Elara Vane** — Lead Reactor Physicist (2151–2157) หนึ่งในทีม 6 คนที่ตาย ปมหลักผ่านบันทึกกู้คืน

### ⚠ วิกฤต 1 · เสถียรภาพพลาสมา — ~Day 12

**Trigger:** HEAT > 80 หรือ Q > 0.3 · มีเวลา 3 วัน

**ลำดับ Trigger (ห้ามสลับ):**
1. `InfoCard "พลาสมาถูกขังด้วยอะไร"` →
2. `InfoCard "หล่อเย็นด้วยขดลวดคู่"` + Kova ×2 + Inner Voice →
3. `Kova → Mira → Kova → Mira` (บทเปิดวิกฤต) + Inner Voice →
4. `EventCard "เสถียรภาพพลาสมา"` → Choice A/B/C → Outcome →
5. `KnowledgeCard #2 (พลาสมา) + #3 (สนามแม่เหล็กคู่)`

```

ในเตาฟิวชัน เชื้อเพลิงร้อนเป็นพลาสมาหลายล้านองศา ร้อนเกินกว่าผนังใดจะทนได้

★ [Info Card] หล่อเย็นเตาด้วยขดลวดคู่
• Toroidal Coils — ขดลวดวงรอบ → ยกเพดานกำลังหล่อเย็น (รับ Boost ได้แรงขึ้น)
• Poloidal Coils — ขดลวดรัดแนวตั้ง กันพลาสมาชนผนัง → ลด HEAT ต่อเทิร์น
→ ถ้า HEAT ไต่ใกล้ 100 ให้เสริมขดลวดก่อนเสมอ อย่าเพิ่งเร่งเตา

Kova: "ไปที่หอควบคุม ติดคอยล์ให้ครบสองตัวก่อน แล้วค่อยคิดเรื่องเร่ง"

```

## ★ สรุปให้โปรแกรมเมอร์ — สิ่งที่ต้องเพิ่มในระบบ (นอกเหนือ GDD §16)

โครงการ์ดต่อวิกฤต = 1 ชุด (ลำดับใหม่ ห้ามสลับ):
```
InfoCard → EventCard → Choice A/B/C → Outcome ×3 → KnowledgeCard (ควิซทบทวน)
```
ตรงกับ CrisisSO + CrisisChoice + QuizQuestionSO ใน GDD §16

1. **InfoCardSO** — ScriptableObject ใหม่ เก็บข้อมูลความรู้ที่เด้ง**ก่อน**ควิซ (ฟิลด์: `title, category, body, ปุ่ม`) ผูก 1:1 กับ CrisisSO/QuestSO
2. **ลำดับ Trigger ใหม่** — InfoCard → EventCard → Choice → Outcome → KnowledgeCard (ห้ามสลับ)
3. **★ ตัด AudioLogSO/VoiceLog + ตัดการคลิกของในอาคารออกทั้งหมด** — ไม่มีไฟล์เสียง ไม่มี interactable เล็ก ๆ ในห้อง (ไม่เข้ากับมุมมองเมือง)
4. **RecordCardSO** — บันทึก Elara ทุกใบเป็น RecordCardSO ที่ **เด้งเป็นการ์ดกลางจอเอง** (reuse ระบบ popup การ์ดที่มีอยู่) ตอน trigger สำเร็จ ผู้เล่นอ่านแล้วกดปิด
5. **★ ระบบกู้คืนบันทึก (Data Recovery)** — ผูก trigger การปลดล็อก RecordCard กับหมุดหมาย:
   - (a) สร้าง+จัดคนเข้าห้องวิจัย → #01
   - (b) สกัด Deuterium → #02
   - (c) เตาเริ่มเดินเครื่อง → #03
   - (d) Day 23/สัญญาณพายุ → #สุดท้าย
6. **★ แผง Records (UI panel ใหม่)** — ปุ่มเมนูข้างจอ เปิดดู RecordCard ทุกใบที่กู้คืนแล้ว ให้ย้อนอ่านได้ (ทำเป็นแท็บใน Codex panel เดิม หรือแยกแผงใหม่ก็ได้)
7. **★ Memorial (สิ่งก่อสร้าง)** — อนุสรณ์ในฐานเป็น building ที่คลิกเปิดแผงรายชื่อทีม 6 คน (ไม่ใช่ป้ายเล็ก ๆ ให้ล่าคลิก) — reuse ระบบคลิกอาคารที่มีอยู่
8. **NpcActor / NpcLine / VoiceLine** — reuse ระบบบทพูดที่มีอยู่ · NPC ใหม่ที่ต้องปลด: **Dorn** (หัวหน้าฟาร์ม, ปลดช่วงเฟส 3 เกษตร)
